## ⌨️ Comandos y pasos importantes

- `pwd` — muestra la ruta de la carpeta en la que estamos.
    
- `git clone` — descarga un repositorio de GitHub a nuestro ordenador.
    
- `cd` — permite entrar o salir de una carpeta.
    
- `ls` — muestra los archivos y carpetas.
    
- `git status` — muestra el estado del repositorio y los cambios.
    
- `git add .` — prepara los archivos modificados para guardarlos.
    
- `git commit -m "mensaje"` — guarda los cambios con un mensaje.
    
- `git push` — sube los cambios a GitHub.
    
- `git remote -v` — muestra las direcciones de los repositorios remotos.
    
- `Use this template` — crea una copia propia de un repositorio en nuestra cuenta de GitHub.
